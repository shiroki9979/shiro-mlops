# `dynamic_horizon_forecast` 超參數與特徵配方研究

本報告記錄針對 ML 任務 `dynamic_horizon_forecast`（全台逐時實際負載動態視界預報）所執行的滾動起點回測基線與超參數／特徵配方研究。

---

## 1. 問題 (Problem)

`dynamic_horizon_forecast` 現行使用的特徵配方（`lags = [1, 2, 24, 48, 168]`、`rolling_windows = [6, 24]`）與 LightGBM 超參數（`n_estimators = 100`、`learning_rate = 0.05`、`num_leaves = 31`）定義於 [`src/shiro_mlops/tasks/dynamic_horizon_forecast.toml`](../../src/shiro_mlops/tasks/dynamic_horizon_forecast.toml)，過去尚未在凍結訓練表快照上以一致的滾動起點回測協定（`horizon_hours = 24`）量化各提前時數（1..24 小時）的基線誤差，也尚未驗證調整滯後階數、滾動視窗與 LightGBM 超參數是否能降低多步遞迴預報的整體 MAPE。

本研究首先在凍結快照上建立現行 TOML 參數的滾動起點回測基線（TICKET-802），再以 Optuna 在搜尋起點上探索候選參數並於不重疊的評估起點上檢驗是否採用（TICKET-803）。

## 6. 結論 (Conclusion)

1. **搜尋起點表現**：在 24 次 Optuna TPE 試驗（`seed = 42`）中，最佳候選 `trial_20`（移除 `lag 48`、`num_leaves = 47`、`learning_rate ≈ 0.0784`、`n_estimators = 75`）於搜尋起點上的整體 MAPE 為 `2.8078%`，雖然在第 1、4–6、8–11、13–15 及 21 小時等分組略低於基線，但因第 22–24 小時長視界遞迴累積誤差上升，整體 MAPE 仍略高於現行 TOML 基線的 `2.7955%`（`+0.0123` 百分點）。
2. **評估起點表現與 48 小時滯後特徵的作用**：在不重疊的評估起點（`2026-10-29 18:00` 與 `22:00`）上，`trial_20` 僅在第 1–2 小時短視界（`0.4908%`、`0.1501%`）優於基線，自第 10 小時起誤差明顯放大，整體評估 MAPE 為 `7.2563%`，顯著劣於基線的 `4.5076%`。這顯示在訓練樣本僅剛跨過 `672` 小時門檻時，提高樹複雜度（`num_leaves = 47`）並移除 `lag 48` 容易對近期日內曲線過度擬合，進而在多步遞迴推論時放大中長視界誤差。
3. **評估樣本跨度限制**：受限於 `2026-10-30 23:00` 起的擷取中斷，本快照在滿足 `min_training_hours = 672` 與目標時段不重疊的條件下，僅有 1 個日曆日（2 個評估起點）可供評估，未達正式採用判定所需的 7 個不同日曆日門檻（`eval_distinct_days = 1 < 7`）。

## 7. 是否採用 (Adoption Decision)

- **決定**：**不採用（維持現行 TOML 設定不變）**。
- **判定依據**：
  1. **評估起點數量不足**：不重疊評估起點僅涵蓋 `1` 個日曆日（2 個整點起點），低於 `MIN_EVAL_DISTINCT_DAYS = 7` 的代表性門檻（`eval_sample_sufficient = False`）。
  2. **評估起點誤差未改善**：即便檢視現有 2 個評估起點，最佳候選 `trial_20` 的整體 MAPE（`7.2563%`）亦高於現行基線（`4.5076%`，`beats_baseline_on_eval = False`）。
- **後續行動**：[`src/shiro_mlops/tasks/dynamic_horizon_forecast.toml`](../../src/shiro_mlops/tasks/dynamic_horizon_forecast.toml) 的 `[params]` 與 `[params.model]` 保持原設定不動；待地端資料庫累積超過兩週以上無缺口有效起點（使不重疊評估起點涵蓋至少 7 個日曆日）後，再重新凍結快照執行下一輪研究。
